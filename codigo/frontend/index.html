Arquitectura Híbrida del Sistema

Diseño desacoplado: Extracción Estructurada + Text-to-SQL + RAG Documental + Control de Trazabilidad.

1

Ingesta y Extracción

Los PDFs son analizados por pypdf y transformados en fichas tipadas con Pydantic v2, guardadas en SQLite e indexadas por fragmentos semánticos.

2

Agente con Function Calling

El LLM (Google Gemini / OpenAI) decide autónomamente si consultar la base de datos (query_project_database) o buscar texto en los PDFs (search_project_documents).

3

Citas y Anti-Alucinación

Toda afirmación incluye el código y nombre del proyecto. Si una consulta indaga sobre temas inexistentes, el agente declara que no hay datos disponibles.
