Preguntas Frecuentes

Todo lo que necesitas saber sobre el funcionamiento del Agente

¿Qué tipo de documentos PDF puede procesar esta herramienta?

Cualquier archivo PDF con texto digital: facturas de luz, agua, gas, extractos bancarios, contratos comerciales, pólizas, informes técnicos de consultoría, balances contables y manuales operativos.

¿Cómo garantizan que la IA no invente datos (alucinaciones)?

El sistema utiliza una arquitectura estricta de Grounding y RAG Híbrido. Cada respuesta cita el código de fuente, página y párrafo. Si una información no existe, el agente declara honestamente que no dispone de datos.

¿Puede hacer sumas, promedios y cruzar datos matemáticos?

Sí. Cuenta con un motor relacional SQLite integrado mediante Function Calling. Puede calcular duraciones promedio, rankings de costos y filtros estructurados con precisión de base de datos.

¿Mis documentos y datos están protegidos?

Absolutamente. El motor de extracción y la base de datos se ejecutan en un entorno seguro y aislado. Los documentos no se utilizan para re-entrenar modelos públicos.
